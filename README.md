This framework is a from-scratch implementation of a Small Language Model (SLM) architecture. Instead of using black-box libraries, it uses pure Matrix Calculus to handle word embeddings and neural logic."

Key Milestones Achieved:

Vector Geometry: Words are mapped to a 4D space where the model "rewrites" their definitions during training.
The Detective Engine: A custom backpropagation system that slices 8D phrase blame into individual word updates.
Non-Linear Intelligence: Uses ReLU "folds" to enable complex conditional logic in the network.
Batch Efficiency: Processes multiple linguistic patterns in parallel using matrix-level averaging.
